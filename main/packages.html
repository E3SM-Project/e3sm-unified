Package Catalog

This page lists the packages in the E3SM-Unified 1.14.0 recipe, along with the most important package constraints. The authoritative source is recipes/e3sm-unified/e3sm-unified-feedstock/recipe/recipe.yaml.

Notes

E3SM-Unified 1.14.0 is published on conda-forge for Python 3.12, 3.13 and 3.14 on linux-64, linux-aarch64, osx-64 and osx-arm64.

The exact environment depends on the selected package variant. Two variants are published:

  • nompi is the default conda-only variant. Use it on laptops, workstations and unsupported systems.

  • hpc omits several system-library-heavy packages from the conda package so they can be provided by the HPC deployment through Spack. It is meant for shared deployments on supported HPC machines.

Conda-forge MPI variants (mpich and openmpi) were last published for E3SM-Unified 1.12.0. Starting with 1.13.0, they are not built because e3sm_diags requires the nompi build of esmf (e3sm_diags#1051).
